5. THE CONTROLS THAT MATTER FOR OUR USE CASE
A. Character and place consistency
The product manual describes global assets, multi-episode references, manual replacement and @asset links. This is a meaningful difference from simply sending disconnected text prompts to a renderer. It does not prove long-season consistency. The manual itself contains a FAQ about inconsistent characters and recommends explicitly referencing the character in the affected storyboard.
Source: https://xyq.jianying.com/tutorials/web-manual

B. Voice identity and acting
The character canvas manual explicitly allows uploading a reference audio file to a character node, in addition to a text description of voice. It does not establish lossless preservation of an uploaded performance, phoneme-accurate lip sync, fixed audio duration across shots or guaranteed emotion.
Source: https://xyq.jianying.com/tutorials/short-drama-agent-canvas
The model-ecosystem page advertises Seed Audio and 20 languages. That page does not enumerate all 20. English examples and language-strengthening guidance appear in the prompt manual. Hindi support and Indian-accent quality remain unverified.
Sources: https://xyq.jianying.com/model-ecosystem
https://xyq.jianying.com/tutorials/seedance-2-5-prompt-guide
The prompt guide advises naming dialogue language, regional variant/accent and delivery. It explicitly discusses English dialogue being spoken in Chinese and suggests strengthening the language instruction. So non-Chinese dialogue is a supported target, but not a guaranteed result.
For acting, the guide recommends specifying visible or audible behavior: gaze, brows, mouth, breathing and hand movements, with triggers and progression. This is useful direction, not evidence of performance reliability.

C. Space, action and camera control
A documented 3D director tool supports static staging, camera positions, FOV, action presets, drawn movement paths and frame-based keyframes in a preview timeline. It exports still/dynamic references back to the canvas. This can reduce ambiguity about who stands where before generating.
Source: https://xyq.jianying.com/tutorials/short-drama-agent-3d-director
Important distinction: a frame-based PREVIEW timeline does not make the final generative output frame-deterministic. The prompt guide says timestamps allocate event rhythm, not frame-accurate cuts. It also says video editing cannot guarantee frame-by-frame matching; output duration can differ from input by up to about 0.3 seconds; extension volume may differ slightly; exact text and frame times need pre/post-production.
Source: https://xyq.jianying.com/tutorials/seedance-2-5-prompt-guide

D. Repair rather than full reroll
Partial reshoot/edit is documented, including billing for the selected segment, not necessarily an entire original clip. Exact minimum billable duration, allowed edit lengths and successful fixes still need a live task quote/test.
Source: https://xyq.jianying.com/tutorials/web-manual

E. Existing-footage remaking is a separate route
The remake manual describes uploading an existing short drama, identifying characters/scenes/props, changing style/target region, using motion references and then synthesizing edited segments. This offers an alternative to wholly text-originated acting.
Source: https://xyq.jianying.com/tutorials/short-drama-remake
There is NO evidence that the supplied Runaway Bride reel used this route. Use owned/licensed source footage only. Remaking a video is not permission to copy it.

LongCat-Video-Avatar-1.5:

Apache-2.0 code; README minimum inference VRAM 8GB for v1.5, 18GB for v1.6. Guidance may improve lip accuracy but can increase distortion/jitter. MuseTalk: https://github.com/TMElyralab/MuseTalk/blob/main/README.md

WhisperX: https://github.com/m-bain/whisperX
