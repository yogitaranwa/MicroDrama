# Sources, checked 2026-10-25
Primary repositories, papers and documentation. Paper claims below are not local generation results.

- pyloudnorm, https://github.com/csteinmetz1/pyloudnorm , MIT code, inspected README and LICENSE; installed 0.2.0 from official PyPI. Used actual meter and loudness normalization in local repair. High confidence.
- Steinmetz/Reiss, pyloudnorm paper, https://csteinmetz1.github.io/pyloudnorm-eval/paper/pyloudnorm_preprint.pdf . BS.1770 implementation/compliance and perceptual limitations. Paper read. High confidence on method, not proof of voice emotion.
- FFmpeg source https://github.com/ffmpeg/ffmpeg and filter docs https://ffmpeg.org/ffmpeg-filters.html . Installed 4.4.2 GPL-enabled binary; decoded and independently measured actual repair. FFmpeg LGPL/GPL configuration-dependent; no binary copied into deliverable.
- VACE repository https://github.com/ali-vilab/VACE , user guide https://github.com/ali-vilab/VACE/blob/main/UserGuide.md , code https://github.com/ali-vilab/VACE/blob/main/vace/vace_wan_inference.py , paper https://arxiv.org/abs/2503.07598 . Apache 2.0 code, Wan VACE checkpoints listed Apache 2.0, LTX checkpoint RAIL-M, upstream license still applies. Reference + pose/depth + masks is a plausible action-control route, not proof of correct table physics. Current repo setup tested CUDA 12.4/PyTorch >=2.5.1. Not run: no GPU.
- Phantom https://github.com/Phantom-video/Phantom , paper https://arxiv.org/abs/2502.11079 . Apache 2.0 repo, single/multi-subject reference video. README warns vertical generation less stable, 14B 720p less stable than 480p. Not run: GPU requirement. Weight/transitive rights must be checked before deployment.
- ConsisID paper https://openaccess.thecvf.com/content/CVPR2025/html/Yuan_Identity-Preserving_Text-to-Video_Generation_by_Frequency_Decomposition_CVPR_2025_paper.html ; implementation documentation https://huggingface.co/docs/diffusers/en/api/pipelines/consisid . Identity-preserving conditioning, not guaranteed outfit/action continuity. Docs memory table baseline 44GB reserved, optimized 7GB reserved. Not run.
- LatentSync https://github.com/bytedance/LatentSync/ , license https://github.com/bytedance/LatentSync/blob/main/LICENSE , inference code https://github.com/bytedance/LatentSync/blob/main/scripts/inference.py , paper https://arxiv.org/abs/2412.09262 . Apache 2.0 repo. Minimum inference VRAM 8GB for1.5,18GB for1.6. Not run; cannot establish natural emotion or make hidden faces visible.
- MuseTalk https://github.com/TMElyralab/MuseTalk/ . MIT code, README says models available commercially, separate dependencies' licenses apply; test media noncommercial only. README 4GB RTX3050Ti example ~5min/8s. Not run. Lower-cost GPU option to test, not a verified fix.
- Wav2Lip https://github.com/Rudrabha/Wav2Lip . README noncommercial research/academic/personal only; commercial use of LRS2-trained model prohibited. Not integrated in a product workflow.
- Magic Hour current models/costs https://docs.magichour.ai/api-reference/models and account API https://docs.magichour.ai/api-reference/account/get-account-details . 48 credits/sec MiniMax H3 720p; Pro lip sync 2 credits/frame, final costs may settle to actual frames. Live GET used for account balance, no POST generation. Not an open-source inference substitute.
- Music source https://incompetech.com/music/royalty-free/mp3-royaltyfree/Grand%20Dark%20Waltz%20Moderato.mp3 and licensing https://incompetech.com/music/royalty-free/licenses/ . Same existing chosen track, attribution must accompany use. Audio metadata and sidecar provided; final video must also carry usable attribution.
