# m20 integration checkpoint

## What this is
Additive local-model integration work, not a finished episode and not proof of successful GPU inference. Existing paid routes remain available and unchanged. No paid generation was performed.

## New paths
- `forge.integrations.registry`: pinned repository catalog and local blockers.
- `forge.integrations.jobs`: real upstream CLI argument/input builders.
- `forge.integrations.contracts`: dependency-free checks of actual argparse declarations.
- `forge.integrations.plan_bridge.prepare_audio_driven_jobs`: existing `build_render_jobs()` output -> selected audio-driven model jobs. Requires a locked still with matching SHA256 and explicit speaker audio. Writes a manifest; does not execute.
- `forge.integrations.runner`: subprocess execution, logs and CUDA/input preflight. Caller must run preflight and review model licenses before execution.
- `forge.integrations.jobs.pulid_sdxl_driver`: actual SDXL PuLID API. The older FLUX-shaped wrapper is retained but fails closed with a correction message.
- `forge.experiments.seed_ab`: matched-control experiment plan, not completed experiments or proof of a cause.
- `forge.integrations.angle_matrix`: identity-preserving reference-angle planning.

## Blockers
No CUDA GPU or model weights here. MultiTalk and InfiniteTalk imports fail closed through xfuser's accelerator check. VACE needs its upstream Wan dependency and model weights. PuLID needs InsightFace and other dependencies; its upstream constructor downloads model files if uncached. No generated output from these models has been inspected. Non-commercial face-model conditions still apply; personal use does not remove license requirements.

## Script selection
Selected existing project script: `out/script_v9/e01_script_v9.json`, "The Debt of Champions". It is ready-made project material, not copied from an external reel. It has 24 shots, 4 locations, 110.8 planned seconds and 2,589 dialogue characters. This selection reuses existing writing, rather than starting another rewrite. The underlying franchise characters are third-party IP; this is not a claim that their commercial rights are cleared.

The full script has five speaking characters and several prop/reveal shots. It is not a sensible first multi-person model stress test. Start with the previously accepted short two-person audio scene and approved identity stills, review the visual/audio result, then expand. The full v9 audio still needs an ear test before video generation. No production run until a total spending cap is approved.

## Ten-episode continuity
Existing season archive/continuity gates remain intact. New model jobs are optional and do not replace those gates. No later episode is generated by this checkpoint.

## Release audit corrections
The initial m19 checkpoint assumed the PuLID library used FLUX. The actual vendored pipeline is SDXL; m20 corrects this and adds API-signature checks. The initial local tests did not catch that mismatch. Test passes are code-level evidence only.
