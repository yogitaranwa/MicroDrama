## Real code findings

- ViMax is MIT. Script2Video forwards motion and audio descriptions as text plus reference frames. It does not forward an approved audio waveform, shot duration, aspect ratio or resolution. The supplied Google backend defaults to 8 seconds, 16:9 and 1080p. Its two-frame branch intentionally falls back to first-frame-only. Camera transitions can add video generation beyond final shot count. Some character/shot/final caches reuse on file existence rather than changed source content.
- ViMax's useful mechanisms are camera-linked image provenance, reusable reference selection and multiple candidate-keyframe audit. These are orchestration, not new synthesis capabilities. Existing pipeline code already has related reference, continuity and quality gates. Duplicating names is not progress.
- ArcReel is AGPL with NOTICE and UI attribution obligations. Its workspace is a larger Python 3.12 stack. Its Ark backend forwards audio references, but reference audio is not evidence of exact waveform/mouth alignment or our output quality. Do not merge into a proprietary service silently.
- Wind Comic is MIT, with a separate Node/Next.js stack. Its built-in no-key lip path is a detached indicative 2D overlay. Real face-level sync needs another engine. Its predev/prebuild helper copies local WASM and checks a bundled model; despite the filename, it does not currently download remotely.
